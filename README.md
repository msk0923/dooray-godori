# 고도리 이모티콘 (dooray-godori)

두레이 메신저에서 슬래시 커맨드로 고도리 이모티콘을 보내는 봇입니다.

```
/고도리 확인
```

## 폴더 구조

```
dooray-godori/
├── images/            # 이모티콘 이미지
│   ├── 01_confirm.png
│   ├── ...
│   └── 14_alone.png
├── app.py             # 슬래시 커맨드 응답 서버
├── emojis.json        # 키워드 ↔ 이미지 파일 매핑
├── requirements.txt   # 서버 실행에 필요한 패키지
└── README.md          # 사용 설명서
```
